# Asset codecs and eight-weight skinning

Implemented the final remaining priority: Draco/Meshopt glTF geometry, Basis ETC1S/UASTC KTX2 texture transcoding and eight-weight GPU skinning. Optional decoders load only on demand; all work stays in the asset preparation path. Eight-weight meshes preserve vertex/instance ABIs and GPU storage-binding count by appending static secondary influences to the shared deformation arena. Color, depth and shadows share deformation; cold rollback, unload and recovery reclaim/rebuild the combined allocation.

Real Chrome production checks require actual compressed extensions with no geometry fallback. Lossless Draco and Meshopt match the uncompressed triangle byte-for-byte in main-thread and worker decoding. Default lossy Draco quantization initially changed one edge pixel; the lossless fixture separates decoder correctness from authored quantization. Four/eight-weight and secondary-only fixtures match full images exactly in individual, instanced and GPU-indirect modes with depth/shadows, including combined morph/skin. GPU LOD selects a separate mesh allocation with a different deformation offset and preserves the image. Basis ETC1S/UASTC upload/render authored six-level mip chains; a fresh device without compression features validates RGBA fallback for both. Live eight-weight geometry plus Basis textures preserve an exact image after device recovery. Warm creation counts stay fixed; final owned buffers/textures reach zero. No scoped/uncaptured GPU or page errors.

Tiny fixture measurements include network/module/worker startup and are not representative throughput comparisons. Initial Draco/Meshopt main-thread loads take about 19/15 ms; subsequent worker loads 28/7 ms. First Basis ETC1S load takes about 79 ms; subsequent UASTC about 4 ms. Fallback transcoding takes about 33.3 ms initially and 0.5 ms subsequently, with 8,520 RGBA mip bytes per 40×40 texture. Small eight-weight scenes complete in roughly 1.1 ms with active depth/shadow draws, compared with 1.1 ms for their four-weight references; timer resolution and scene size prevent a meaningful GPU cost claim. CPU validation/copy/normalization of 10,000 vertices averages 0.503 ms for four weights and 1.055 ms for eight, about 2.1× more cold work.

Supported Basis input is straight-alpha 2D ETC1S/UASTC with Rec.709/unspecified primaries, rd orientation and rgba swizzle. Unsupported HDR output, cubemaps/arrays and alternative metadata reject explicitly. Native KTX2 supercompression remains unsupported independently of Basis transcoding. More than eight skin weights reject. Decoder behavior follows [glTF Transform extensions](https://gltf-transform.dev/extensions) and [Three.js KTX2Loader](https://threejs.org/docs/pages/KTX2Loader.html); Three never owns project rendering.

Reproduce: `node scripts/create-codec-fixtures.mjs`, `npm test`, `npm run build`, `npm run validate:codecs`, `npm run benchmark -- tests/skinning.bench.ts --outputJson artifacts/codecs-cpu.json`. See `results/codecs.json` and `results/codecs-cpu.json` for measured values. Fixture provenance is in `public/regression/CODEC_FIXTURES.md`.

Final integration gates: 203 tests across 53 files, strict production build, formatting/diff checks and all renderer/asset/game/lighting/HDR/recovery/environment/codec GPU validations pass. The default matrix retains all 86 prior counter/resource snapshots exactly. The final long matrix preserves exact stateless-reference images; 1,000×64-joint CPU/completion medians are 24.9/28.4 ms. These independent runs remain subject to scheduling/JIT variance and exceed a 60 FPS CPU budget. Final matrix/regression evidence: `results/remaining-final-{matrix,long-matrix,regression}.json`.
